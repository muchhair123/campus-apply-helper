# 校招网申助手 🧩

一个纯本地运行的 Chrome / Edge 浏览器插件，帮你应对国企/私企/外企等校招网申的重复填表。

## 功能

1. **个人信息库** —— 本地保存结构化简历信息（基本信息 / 教育 / 工作实习 / 项目 / 技能证书 / 奖项 / 家庭成员 / 求职意向）。支持上传简历（PDF / Word / LaTeX）自动解析草稿，也可手动编辑。**可自定义新增模块与字段**，也能给内置模块挂载自定义字段。
2. **一键填写** —— 在网申页面右侧注入侧边栏，点一下把信息库里的已知字段智能填入当前页面表单。支持 Element UI 等框架的**下拉安全自动选**（匹配不到则留给你手选）。识别不到值的字段会列出提示你手填，填完可一键回写到信息库——**回写时按页面区块自动归类到对应模块**。
3. **投递记录面板** —— 按公司 / 岗位记录投递情况（状态、日期、链接、备注），在网申页点「记录本次投递」半自动抓取当前页信息。

**全程不联网、不接任何 AI 服务**，数据只存在你本地浏览器（`chrome.storage.local`）。

> ⚠️ **隐私说明**：本仓库不含任何真实个人信息。`example-profile.json` 是**空白格式示例**；你自己的信息库数据只保存在本地浏览器，导出的备份 JSON 请妥善保管、不要公开。

## 安装（开发者模式加载）

Chrome / Edge 通用，加载同一个目录即可：

1. 打开扩展管理页：
   - Chrome：地址栏输入 `chrome://extensions`
   - Edge：地址栏输入 `edge://extensions`
2. 打开右上角 **开发者模式**
3. 点 **加载已解压的扩展程序**（Edge：**加载解压缩的扩展**）
4. 选择本目录 `apply-helper/`
5. 浏览器工具栏出现 📝 图标即安装成功

## 使用

1. **先填信息库**：点工具栏图标 → 「个人信息库」，手动录入，或上传简历（推荐 `.tex` 源文件，中文识别最全；中文 PDF 可能因字体问题识别不到汉字）。记得点「保存信息库」。
   - 也可点设置页「导入备份」导入一份 JSON；仓库里的 `example-profile.json` 是空白格式示例，可照着填。
2. **填网申**：打开某公司网申页 → 点工具栏图标 → 「在当前页面打开侧边栏」 → 点「⚡ 一键填写当前页面」。
   - 绿色高亮 = 已填；黄色高亮 = 匹配到但未成功（下拉/单选需手动选）。
   - 侧边栏会列出信息库里没有的字段，你手填后点「把我填的新值保存到信息库」即可沉淀下来。
3. **记录投递**：在网申页侧边栏点「＋ 记录本次投递」，确认公司/岗位/链接后保存。到「投递记录」tab 查看、改状态、点链接回访。
4. **备份**：设置页右上「导出备份」下载 JSON；换电脑后「导入备份」恢复。

## 设计原则

- **宁缺毋填**：字段匹配基于启发式打分，低置信度的不自动填，避免填错污染表单。
- **解析不覆盖**：简历解析结果作为「草稿」合并进表单，不覆盖你已有的非空值，需你确认后保存。

## 已知限制

- **中文 PDF**：若简历 PDF 用特殊中文字体编译且缺少 ToUnicode 映射，pdf.js 提取不到汉字（只能拿到手机/邮箱/英文）。→ 改用 `.tex` 源文件，或手动补中文字段。
- **跨域 iframe**：部分网申表单嵌在跨域 iframe 里，浏览器安全策略下插件无法填充，需手动。
- **字段同义词表**：覆盖了常见几十个字段，遇到填不中的字段，可在 `lib/profile-schema.js` 的对应 `aliases` 里补关键词。

## 目录结构

```
apply-helper/
├── manifest.json          # MV3 配置
├── background.js          # service worker：消息中枢
├── content/content.js     # 侧边栏注入 + 填充 + 抓投递信息
├── popup/                 # 工具栏弹窗
├── options/               # 信息库 + 投递记录主界面
├── lib/
│   ├── profile-schema.js  # 字段定义（单一数据源）
│   ├── field-matcher.js   # 启发式匹配引擎
│   ├── resume-parser.js   # 简历解析
│   ├── storage.js         # 存储封装
│   └── vendor/            # pdf.js、mammoth
└── test/                  # 本地测试页（不影响插件运行）
```

## 本地测试（可选）

`test/` 下有带 `chrome.storage` mock 的测试页，用于不装插件验证 UI/逻辑：

```bash
cd apply-helper
python3 -m http.server 8731
# 浏览器打开 http://localhost:8731/test/options-test.html（信息库+投递面板）
#          http://localhost:8731/test/mock-form-integration.html（侧边栏一键填写）
```
